키 입력은 이 페이지 안에서만 작동해요.

딸깍, 이렇게 즐겨보세요.

  1. 키캡을 눌러보세요. 휴대폰에서는 터치, PC에서는 화면 클릭이나 실제 키보드로 소리를 낼 수 있어요. 동시에 여러 키를 눌러도 돼요.
  2. 모양을 바꿔보세요. 오브제 16종, 기본 키캡, 키보드를 고를 수 있어요. 모든 키 배열은 반듯하게 정렬됩니다. 오브제에서도 QWE / ASD / ZX / Enter로 연주할 수 있어요.
  3. 취향을 골라보세요. 스위치를 선택하면 짧은 샘플을 들려드려요. 컬러·둥근 모서리·소리 높이도 바꿀 수 있어요.
  4. 내 리듬을 남겨보세요. 녹음 → 직접 연주 → 정지 → 재생 또는 WAV 저장. 최대 30초이며 키 소리만 담겨요.
  5. 마음에 드는 조합은 저장. 최대 6개를 이 브라우저에 보관해요. 저장한 조합을 누르면 다시 적용돼요.
  6. 음악과 진동을 함께. 음악 4곡을 선택하고 타건음과 별도로 음량을 조절해보세요. 진동의 약·중·강은 길이와 패턴을 바꾸는 방식이며, 진동을 지원하는 기기·브라우저에서만 작동합니다.

소리가 안 나면 키캡을 다시 누르고 기기 미디어 음량을 확인해주세요. 소리는 처음 터치한 뒤 재생됩니다. 설정·조합은 기기 간 동기화되지 않으며, 브라우저의 저장 공간을 지우면 사라져요. 녹음은 페이지를 닫기 전에 WAV로 저장해주세요.

휴대폰 기본 키보드를 바꾸는 앱은 아니며, 이 화면 안에서 즐기는 웹앱입니다. 자연 배경음과 음악은 타건 녹음에 포함되지 않아요. 화면을 떠나면 음악은 멈추며, 돌아와서 재생을 누르면 이어집니다.
